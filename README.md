# Wodburn Radar — Formulário Público

Frontend público e responsivo do mapeamento comercial da Wodburn Company.

**Formulário:** `https://diego2216.github.io/agencywb-formulario/`

**Estrutura:** página inicial premium com botões funcionais, questionário de 4 etapas, campos de cadastro e diagnóstico, consentimentos separados, aviso de privacidade e retorno de protocolo em envio bem-sucedido.

**Armazenamento:** API Supabase Edge Function Wodburn Radar. Os dados e o painel administrativo permanecem privados, fora deste repositório. Nenhuma credencial secreta é armazenada no frontend.

**Operação:** publicação via GitHub Actions / GitHub Pages do repositório público. A URL só deve ser enviada depois de validar a publicação e um cadastro teste.

**Privacidade:** verifique o contato `grupowodburn@gmail.com` e confirme a política LGPD com a Wodburn antes de distribuir amplamente. Proteção adicional antispam recomendada.
